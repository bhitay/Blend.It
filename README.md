# BlendIt

אפליקציית ניהול כספים משפחתית: עו"ש, כרטיסי אשראי, פנסיה, קרן השתלמות, גמל, השקעות, נדל"ן ומשכנתאות, במקום אחד ומשותף לשני בני הזוג.

## מבנה

| תיקייה | מה יש בה |
|---|---|
| `app/` | אפליקציית האייפון/אנדרואיד (Expo + React Native, עברית מימין לשמאל) |
| `supabase/migrations/` | סכמת מסד הנתונים והרשאות (כל משק בית רואה רק את הנתונים שלו) |
| `sync/` | *(שלב 2)* שירות סנכרון שרץ על המחשב בבית ומושך תנועות מהבנקים ומכרטיסי האשראי |

## מפת דרכים

- [x] **שלב 1: שלד.** התחברות, משק בית משותף עם קוד הזמנה, חשבונות ויתרות בהזנה ידנית, מסך שווי נקי.
- [ ] **שלב 2: סנכרון בנקים ואשראי.** מזרחי טפחות, דיסקונט ואוצר החייל (וכרטיסי האשראי) עם `israeli-bank-scrapers`, על המחשב בבית.
- [ ] **שלב 3: הוצאות.** סיווג אוטומטי, הוצאות קבועות מול משתנות, תקציב.
- [ ] **שלב 4: פנסיה, השתלמות, גמל וביטוח.** ייבוא דוחות (הר הכסף, מסלקה פנסיונית, הר הביטוח).
- [ ] **שלב 5: השקעות.** תיקי ני"ע ותשואות.
- [ ] **שלב 6: נדל"ן ומשכנתאות.**

## הרצה בפעם הראשונה

### 1. Supabase (מסד הנתונים וההתחברות)

1. נרשמים ב-[supabase.com](https://supabase.com) ויוצרים פרויקט חדש. האזור הקרוב לישראל הוא **Central EU (Frankfurt)**. את סיסמת מסד הנתונים שומרים בצד.
2. בפרויקט פותחים **SQL Editor**, מדביקים את כל התוכן של `supabase/migrations/0001_init.sql` ולוחצים **Run**.
3. ב-**Authentication → Sign In / Providers → Email** אפשר לכבות את **Confirm email**, כדי שלא יידרש אימות במייל. השימוש הוא רק של שניכם, אז זה בסדר.
4. ב-**Project Settings → API Keys** מעתיקים את ה-**Publishable key**. את כתובת הפרויקט (`https://xxxx.supabase.co`) מעתיקים מ-**Data API**.

### 2. הגדרת האפליקציה

```bash
cd app
cp .env.example .env      # ממלאים את הכתובת והמפתח משלב 1.4
npm install
npx expo start
```

### 3. פתיחה באייפון

1. מתקינים באייפון את **Expo Go** מה-App Store.
2. האייפון והמחשב צריכים להיות על אותה רשת Wi-Fi. סורקים את קוד ה-QR שמופיע בטרמינל עם המצלמה.
3. נרשמים, יוצרים משק בית, ומ**הגדרות** שולחים את קוד ההזמנה לבן/בת הזוג. הם נרשמים באייפון שלהם ובוחרים "הצטרפות עם קוד".

> בהפעלה הראשונה ב-Expo Go ייתכן שהמסך עוד לא יהיה מימין לשמאל. סוגרים את האפליקציה ופותחים שוב.
> בהמשך נבנה גרסה שמותקנת כמו אפליקציה רגילה דרך TestFlight. לזה צריך חשבון Apple Developer.

## פיתוח

```bash
cd app
npx tsc --noEmit     # בדיקת טיפוסים
npx expo start --web # תצוגה בדפדפן
```

### אבטחה

- המפתח שבאפליקציה (Publishable) ציבורי מטבעו. ההגנה על הנתונים מגיעה מ-Row Level Security: כל משתמש רואה רק משקי בית שהוא חבר בהם (`is_household_member`).
- סיסמאות הבנקים **לא** נשמרות באפליקציה ולא ב-Supabase. בשלב 2 הן יישמרו רק על המחשב בבית, בשירות הסנכרון.
- הקובץ `app/.env` לא נכנס ל-git.
